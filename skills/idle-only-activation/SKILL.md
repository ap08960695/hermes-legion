# Idle Only Activation

Before activation, verify current native worker/session/background process identities and an idle stable window. Back up affected files and supported state. Use the normal application or service lifecycle once, then verify fresh canonical source and retained session/model/goal controls. Stop on ambiguous lifecycle results without replay. Reopening a session can fire an existing schedule; account for that activity honestly.

Use only existing authorized provider lanes and native quotas. No paid fallback, allowance probes or model-backed polling. Preserve owner decisions, rights, review and publication gates. Do not interrupt active workers or modify unrelated services. Report meaningful completion, failure or a material owner question; stay quiet on unchanged waits. Role guidance confers no additional tool or filesystem permission.
