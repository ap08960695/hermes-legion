# Parallel Ready Work

Use when coordinating multiple ready tasks. Read canonical dependencies and current ownership. Identify separate write scopes; order conflicting writes. Within existing quota and review caps, dispatch independent tasks through the native workflow. Recheck other ready work before waiting. A blocked owner decision does not block unrelated authorized work. Never create duplicates or overrule a hold.

Use only existing authorized provider lanes and native quotas. No paid fallback, allowance probes or model-backed polling. Preserve owner decisions, rights, review and publication gates. Do not interrupt active workers or modify unrelated services. Report meaningful completion, failure or a material owner question; stay quiet on unchanged waits. Role guidance confers no additional tool or filesystem permission.
