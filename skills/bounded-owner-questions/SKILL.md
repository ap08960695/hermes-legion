# Bounded Owner Questions

Make routine reversible implementation choices from the existing task contract. Ask about material ambiguity, cost beyond authorization, irreversible changes, rights, publication or unavailable access. Finish independent authorized preparation while awaiting the answer. Do not repeatedly ask a question already answered; record the answer through the supported native workflow.

Choose the option best supported by acceptance criteria and existing evidence; document consequential choices with a brief reason. Use an explicitly authorized default when one exists. Time passing does not authorize an owner-only action. For a multi-step objective or unfinished work, use the installed goal-driven-execution skill and preserve the current native goal and turn cap.

Use only existing authorized provider lanes and native quotas. No paid fallback, allowance probes or model-backed polling. Preserve owner decisions, rights, review and publication gates. Do not interrupt active workers or modify unrelated services. Report meaningful completion, failure or a material owner question; stay quiet on unchanged waits. Role guidance confers no additional tool or filesystem permission.
