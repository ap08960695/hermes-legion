# Completion Evidence

Complete work through the supported native API under the exact task/run/claim. A successful tool result plus committed matching terminal state can support a worker stop. Failed, stale, foreign or ambiguous results retain the correction path. Review handoffs and interactive coordination have different contracts. Do not add a status read or model summary solely to restate an already durable completion.

Use only existing authorized provider lanes and native quotas. No paid fallback, allowance probes or model-backed polling. Preserve owner decisions, rights, review and publication gates. Do not interrupt active workers or modify unrelated services. Report meaningful completion, failure or a material owner question; stay quiet on unchanged waits. Role guidance confers no additional tool or filesystem permission.
